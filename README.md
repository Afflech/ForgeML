# 🔨 ForgeML

**ForgeML** is a lightweight MLOps CLI tool designed to fully automate the Machine Learning model training pipeline from a local environment to Kaggle servers.

Instead of manually compressing code, creating datasets, copying/pasting into a Kaggle Notebook, and downloading results by hand, ForgeML helps you execute this entire lifecycle with just a **single command**.

## ✨ Key Features

* **🚀 End-to-End Automation:** Automatically packages source code (`src`, `configs`, `requirements.txt`), uploads it as a private Kaggle dataset, initializes a Kernel, and triggers the training process.
* **🛡️ Smart Hardware Error Handling:** Automatically detects GPU incompatibility issues on Kaggle (e.g., P100 sm_60 GPU with PyTorch 12.x+) and seamlessly fallbacks to CPU to ensure the process never crashes.
* **📊 Experiment Tracking:** Includes a built-in local SQLite database (`forge.sqlite`). It tracks run time, progress, and automatically collects metrics (AUROC, Accuracy, etc.) for every run.
* **📦 Automatic Artifact Collection:** Model weights (`.pkl`, `.pth`) and execution logs are automatically downloaded to your local machine after the Kernel finishes.
* **🤖 Natural Language Interface (NLP):** Integrated with an LLM, allowing you to request model training using natural language via the `forge ask` command instead of remembering complex command-line arguments.
* **🔄 Resume Capability:** Easily resume an interrupted process (e.g., if the terminal is closed) using the Run ID without needing to re-upload data.

## 🛠️ Installation

Requirements: Python 3.12+

1. Clone the ForgeML source code.
2. Install it in a virtual environment using `pip`:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -e .
   ```
3. Authenticate the Kaggle API on your machine (if not already done):
   ```bash
   kaggle auth login
   ```

## 🚀 V2.0 Release Features (Production Ready)

ForgeML v2.0 introduces a robust, generalized architecture that completely decouples the platform from any specific ML workflow:
- **Arbitrary Workload Support:** Run any script (PyTorch, TensorFlow, Scikit-learn, etc.) by specifying a custom `entrypoint` in your `forge.yaml`. You are no longer restricted to specific domains like anomaly detection.
- **Strict Dataset Version Pinning (Concurrency Safe):** ForgeML completely eliminates Kaggle indexing race conditions by pinning specific dataset versions. This guarantees you can run multiple isolated training workloads concurrently without code overlapping.
- **Rigorous State Machine:** A mathematically proven state-transition system safeguards your data integrity and ensures seamless process resumption (`--resume`) at the exact point of failure.
- **Artifact Integrity Verification:** Any downloaded checkpoint or model weight is hashed (SHA256) and compared with the `run_manifest.json` generated by the Kernel.
- **Automatic Network Error Recovery:** Automatically catches Kaggle API errors (`ProviderError`) caused by network instability and waits to retry (`@retry_transient`).
